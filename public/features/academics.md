# AXON Academics & Timetables
The engine for managing the school's core academic structure, scheduling, and evaluations.

## Core Features
*   **Academic Setup:** Configure academic years, create classes/sections, and allocate subjects to specific teachers.
*   **Timetable Builder:** A drag-and-drop builder for assigning teachers and subjects to daily periods with built-in conflict resolution (prevents overlapping teacher assignments).
*   **Exam Management:** Configure exams with pass marks, practical/internal mark inclusions, and custom grading rules. 
*   **Results & Analytics:** Enter marks directly into the system to automatically calculate class averages, determine grades, and generate topper/bottom-performer analytics.
