# AXON School Onboarding Guide
Standard operating procedure for the Super Admin to onboard a new tenant (school).

## Onboarding Steps
1. Navigate to the **Super Admin Dashboard** > **Quick Actions** > **Add School**.
2. Input basic tenant information (School Name, unique School Code, Address).
3. Set up the primary **School Admin** credentials (Admin Name, Email, Password).
4. Assign a **Subscription Plan** (select tier, duration, features, and max users).
5. Configure **Feature Toggles** (enable or disable optional modules like LMS, Transport, or HR based on the subscription tier).
6. Save and trigger the automated welcome email containing the School Admin's login portal link.
